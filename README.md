# PMI CAPM & PMP Certification Practice Questions (1 - 1250)

Welcome to the comprehensive practice question repository for the certifications.

## 📖 Overview

This collection contains **1,250 high-quality practice questions** designed to help candidate project managers master key principles, process groups, performance domains, and practical scenarios outlined in the **PMBOK® Guide** and PMI best practices.

### Key Features
- **Comprehensive Coverage**: Questions span Predictive, Agile, and Hybrid project environments.
- **Detailed Analysis & Rationale**: Each question features a collapsible analysis table explaining why the correct option is right while highlighting key PMBOK principles.
- **Color-Coded Feedback**: Visually distinct green ($${\color{lightgreen}\text{Correct}}$$) and red ($${\color{red}\text{Incorrect}}$$) indicators for rapid review.
- **PMI Alignment**: Covers foundational Knowledge Areas, the 8 Performance Domains, the 12 Principles of Project Management, and the Process Groups.

## 🎯 Tips for Effective Study

1. **Focus on the Rationale**: Don't just memorize the correct letter. Read the detailed analysis to understand *why* an answer aligns best with PMI's mindset.
2. **Master the Formulas**: Practice Earned Value Management (EVM) equations ($$CPI = EV / AC$$, $$SV = EV - PV$$), Network Diagrams (Critical Path, Float), and Communication Channels ($$n(n-1)/2$$).
3. **Adopt the PMI Mindset**: Always consider proactive communication, formal change control, root-cause analysis, and servant leadership as primary response strategies.
