**Question 24**: What is the schedule performance index (SPI) if the planned value (PV) is \$100, the actual cost (AC) is \$150, and the earned value (EV) is \$50?

*   A. 0.50
*   B. 0.67
*   C. 1.50
*   D. 2.00

<details>
  <summary>Analysis</summary>

| Option | Description |
| :--- | :--- |
| $${\color{lightgreen}\text{A}}$$ | The Schedule Performance Index (SPI) is calculated as Earned Value (EV) divided by Planned Value (PV). So, SPI = \$50 / \$100 = 0.50. |
| $${\color{red}\text{B}}$$ | 0.67 is the Cost Performance Index (CPI) if EV was \$100 and AC was \$150, or an inverted calculation error (\$100 / \$150). |
| $${\color{red}\text{C}}$$ | 1.50 is the result of dividing Actual Cost by Planned Value (\$150 / \$100), which is not a valid EVM metric. |
| $${\color{red}\text{D}}$$ | 2.00 is the inverted calculation of Planned Value divided by Earned Value (\$100 / \$50). EV must always be in the numerator. |

</details>
