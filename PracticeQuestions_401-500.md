**Question 401**: A work package has been scheduled to cost \$1,000 to complete and was to be finished today. As of today, the actual expenditure is \$1,200 and approximately half of the work has been completed. What is the cost variance?

*   A. -700
*   B. -200
*   C. 200
*   D. 500

<details>
  <summary>Analysis</summary>

  | Option | Description |
  |:---|:---|
  | $${\color{lightgreen}\text{A}}$$ | Cost Variance (CV) is calculated as Earned Value (EV) minus Actual Cost (AC). With half of the work completed, EV is 50% of the \$1,000 budget, which is \$500. AC is \$1,200. Thus, CV = \$500 - \$1,200 = -\$700. |
  | $${\color{red}\text{B}}$$ | -\$200 is obtained by incorrectly subtracting Planned Value (\$1,000) from Actual Cost (\$1,200), ignoring the percentage of actual work completed. |
  | $${\color{red}\text{C}}$$ | +200 is obtained by taking PV minus AC (\$1,000 - \$1,200) without accounting for the negative sign or work completed. |
  | $${\color{red}\text{D}}$$ | +500 is the Earned Value (EV) itself (\$1,000 * 50%), not the cost variance. |

</details>

**Question 500**: The project manager at an organization has just realized that some of the engineering staff has been allocated to project Y and will not be available to finish task X. The project manager has also discovered that at the current pace, it will not be possible to complete the project on time. Due to cost constraints, hiring more work force is not a viable option. Which tools are at the manager's disposal?

*   A. Resource leveling and fast tracking
*   B. Fast tracking and crashing
*   C. Crashing and applying leads and lags
*   D. Scheduling tools and applying leads and lags

<details>
  <summary>Analysis</summary>

  | Option | Description |
  |:---|:---|
  | $${\color{lightgreen}\text{A}}$$ | Resource leveling addresses resource conflicts (staff allocation issues), while fast tracking compresses the schedule without increasing costs by performing tasks in parallel, making them ideal under cost constraints. |
  | $${\color{red}\text{B}}$$ | Crashing adds resources (overtime, extra personnel), which increases costs and violates the given cost constraint. |
  | $${\color{red}\text{C}}$$ | Crashing increases costs, which cannot be used under the stated cost constraints. |
  | $${\color{red}\text{D}}$$ | Scheduling tools do not resolve resource over-allocations without applying leveling optimization techniques. |

</details>
